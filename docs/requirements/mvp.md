# わたくしごと 最初の公開（MVP仕様）

コンセプト: `docs/design/concept.md`

## 目的
- 精神科・心療内科に通う人が、毎日の短い睡眠・調子の記録と話すことメモを、診察やカウンセリングで見せる1画面にまとめ、言い忘れずに伝えられるようにする。
- AIアプリを持つ人は、記録とメモから「何を誰に相談すればいいか」を外部AIアプリで整理できる。
- プレッシャーを避け、記録できない日も責めない静かな体験を守る。

## 画面とできること

### 下のタブ
- 「記録」「診察」の2タブ（アイコン＋ラベル）。
- 設定の「使うもの」で片方だけオンのときは、2つ目のタブ名と画面見出しを「診察」または「カウンセリング」に合わせる。両方オフのときは2つ目のタブを隠す。
- 深さ1のサブ画面（睡眠・調子・これまで・設定）を開いているあいだは下のタブを隠す。
- 初めて開いたときだけ、短い使い方ガイドを出す（スキップ可。普段は右上の「？」からいつでも開ける）。

### 記録タブ（開いたときの画面）
- 上部：日付ナビ（`◀ M/D(曜) ▶`。今日より先には行けない）、右上に「使い方（？）」と「設定（歯車）」。
- 通知バナー（最上部・独立配置）：予定日当日、または予定日を過ぎて未記録の診察・カウンセリングがあるとき、選択中の日が「今日」または「その予定日」のときだけ表示する（診察・カウンセリング両方の同時表示に対応）。押すと「記録する」シートを開く。
- 日々の記録（上にまとめる）：
  - **睡眠**：記録があれば長さのみ表示（例：`6時間6分`、二度寝があれば下の行に `二度寝 1時間30分`）。押すと睡眠画面を開く。
  - **調子**：未記録なら入口ボタン。記録があればカード内にその日の記録行（時刻・ココロ顔・カラダ電池・ひとこと）を表示し、1タップで編集・削除できる。右上の「＋」で同じ日に追加できる。
  - **これまで**：今月の記録日数と合計日数を表示。押すと「これまで」画面を開く。
- 見出し「診察・カウンセリング」（片方のみオン時はその名前、両方オフ時は非表示）の下に：
  - **話すこと**：左側を押すと診察タブへ移動、右の「＋」で話すこと追加シートを開く。

### サブ画面：睡眠
- 上部：戻る、「睡眠」、右上に削除ボタン（削除時は元に戻すトースト）。
- 対象日の表示（「前日の夜 → 当日の朝」）。
- 夜の睡眠：寝た時刻・起きた時刻（5分単位）。未記録日の初期値は以下による。
  - 寝た時刻：「使用状況へのアクセス」が許可されていれば、さかのぼって16時間のうち、いちばん長い画面オフ（3時間以上）の始まり。許可がなければ前回の記録の時刻。
  - 起きた時刻：同じ権限があれば、その画面オフの終わり（つぎに画面がついた時刻）。許可がなければ前回の記録の時刻、記録もなければ開いた時刻。
  - 推定したときだけ、画面オフ時間からの推定である旨の短い注釈を出す。
- 二度寝・昼寝：「＋ 二度寝・昼寝」ボタンで入力欄を追加でき、「×」で外せる。
- 下部の「保存する」ボタンで保存する。

### サブ画面：調子（2ページ）
- 上部：戻る、2段階の進捗インジケータ、右上に削除ボタン（編集時のみ。削除時は元に戻すトースト）。
- 1ページ目：ココロ（顔の5段階。左がつらい、右が楽。選んだ位置まで塗られ表情と色がそろう）、カラダ（5区切りの電池。選んだ位置まで段階の色で塗る）→「次へ」。
- 2ページ目：ひとこと（任意）→「保存する」。
- ココロ・カラダ・ひとことのすべてが空のまま保存した場合は何も増やさず戻る。
- 保存時、ひとことに自傷・自殺を示す語があれば相談窓口シートを出す（語の範囲と扱いは主治医に確認予定）。

### サブ画面：これまで（個人で長期的に振り返る）
- 上部：戻る、月送り（`◀ YYYY年M月 ▶`。今月より先には行けない）、右上に「一覧 / グラフ」切替ボタン。
- グラフ表示時：
  - 1枚のカードに、月平均（平均睡眠・平均ココロ・平均カラダ）と、横軸を揃えた「ココロ・カラダ折れ線」＋「睡眠棒（夜＋二度寝＋平均の点線）」を上下に並べる。
  - 点や棒を押すと、その日の詳細カードが開き、各行タップで睡眠・調子の編集画面へ直接進める。
- 週ごとの折りたたみリスト：
  - 当月の「今週」だけ初期展開し、先週以前は週単位の折りたたみ行（ココロの振れ幅・平均睡眠つき）にする。
  - 右上の「一覧」を押すとグラフを隠し、全週を展開して生の記録をすぐ読めるようにする。
  - 1日に調子が複数件ある日は折りたたまれ、閉じているときはひとことを `/` 区切りで1行表示する。

### 診察タブ（準備 / 見せる）
- 上部：セグメント切替「準備 / 見せる」、右上に「次の予定（カレンダーアイコン）」と「使い方（？）」。
- 次の予定シート（右上カレンダーアイコンから開く）：
  - プレッシャーを避けるため準備画面には常時表示せず、開いた直後は「閲覧モード」として診察・カウンセリングそれぞれの次回日時（年は出さず `M/D(曜)` と時刻、あと何日／今日／記録待ち）を大きく見やすく表示する。
  - 下部の「予定を編集」（すべて未定なら「予定を設定」）を押すと「編集モード」に切り替わり、診察・カウンセリングの日付・時刻の入力と消去をまとめて行える。

#### 準備
- **話すこと**カード：未相談メモを新しい順に表示。右上の「＋」で追加。各メモを押すと編集・相手分類（未分類・診察・カウンセリング）・削除（元に戻すトースト）ができる。下部に「AIで整理」「答えを貼る」ボタン。
- **AIの整理**カード：貼ってあるときだけ表示（両方オン時は診察/カウンセリング別に分けて表示）。「消す」（元に戻すトースト）で削除。
- **前回のアドバイス**カード：最新の診察・カウンセリングそれぞれのアドバイスを色帯つきで表示（記録がなければ非表示）。
- **これまで**行：押すとシートを開き、過去の診察・カウンセリング記録の一覧、「＋ 予定になかった日を記録」、「話したこと」一覧（押すと「話すこと」へ戻せる）を表示する。

#### 見せる（前回からの客観データを相手に伝える）
- 上部：相手切替（診察 / カウンセリング。両方オン時のみ表示）と期間表示（前回記録の翌日から今日まで。前回がなければ直近30日）。
- **今回話すこと**カード：その相手向け＋未分類のメモ一覧。その相手向けの「AIの整理」があれば折りたたみ入口からシートで開ける。
- **診察モード**：期間内の平均（睡眠・ココロ・カラダ）＋ココロ・カラダ折れ線＋睡眠棒グラフ（夜＋二度寝）。日を押すとその日の詳細カードを出す。
- **カウンセリングモード**：「最近の出来事・気持ち」（ひとこと記録を新しい順最大10件）と「前回の振り返り」（前回のアドバイス）。

### 診察・カウンセリングの記録シート（「記録する」）
- 記録タブの予定日通知バナー、または診察タブ「準備」→「これまで」→「＋ 予定になかった日を記録」から開く。
- 入力項目：相手（診察 / カウンセリング）、日付、話したことのチェックリスト（チェックしたメモは「話したこと」へ移り、外したものは次回へ残る。その相手向け＋未分類を初期チェック）、アドバイス、次の予定（日付・時刻、任意）。
- 保存すると、選んだ相手の「AIの整理」をクリアし、記録日以前の予定を済んだものとして消去、次の予定が入力されていれば更新する。

### AIで整理する（外部AIアプリ共有方式）
- 1回の指示文で「振り分け（診察 / カウンセリング）」と「大事な順に3つまで1〜2文で要約」をまとめて依頼する（片方のみオン時はその相手向けに要約）。
- 渡す内容：指示文（診断や薬の判断はしない）＋前回のアドバイス＋未相談メモ＋前回からの記録（日付・平均ココロ・平均カラダ・睡眠時間・ひとこと）。両方オン時は前回から長い方の期間をまとめて渡す。
- 自傷・自殺を示す語を含む文（メモ・ひとこと）は渡す内容から外し、確認シートに外した件数と相談窓口を出す。
- 確認シートでは渡す全文をスクロール確認でき、「コピー」と「アプリ（Androidの共有 `Intent.ACTION_SEND`）」から選べる。
- 「答えを貼る」：貼り付けシート（クリップボードに文があれば初期入力）から保存。`【診察】`/`【カウンセリング】` の見出しと `メモ: #番号` を解析して相手別に自動振り分け・保存し、見出しのない自由文はそのまま保存する。

### 設定
- **使うもの**：診察・カウンセリングそれぞれのオン/オフスイッチ（オフにしても記録は消さず表示のみ隠す）。
- **睡眠時刻の自動入力**：「使用状況へのアクセス」設定画面を開くボタンと許可状態の表示、用途の説明（画面のオン・オフ時刻のみ参照し端末外には出さない）。
- **バックアップ**：JSON の書き出し（SAF で保存先を選択）・読み込み（既存データとマージ。同じ日の睡眠や同一IDは安全に統合）。

## 今回つくらないもの
- アプリの中でAIを呼ぶこと（APIキー、ローカルLLM同梱ともに不採用。渡す文を作る処理は独立した関数に分けておく）
- AIとのチャット、CBTワーク、ルーティン・習慣管理、ホーム画面、服薬の記録、プッシュ通知・リマインダー、アプリ独自の画面ロック
- タグ、気持ちの変化の細分化
- PDF・画像の書き出し、日本語以外への対応

## 基本仕様・技術構成
- 睡眠の推定：`SleepGuess`（`guessBedMinutes` / `hasUsageAccess` / `roundToStep` 5分単位）。マニフェストの `PACKAGE_USAGE_STATS`
- 危機判定：`Crisis`（`looksLikeCrisis`）
- 記録の日付：起きた日（11/13の朝に入れた睡眠 11/12 23:30〜11/13 7:00 は 11/13 の記録）
- アプリ名 / `applicationId`：わたくしごと / `io.github.likeud0n.watakush1goto`
- ライセンス：MIT（同梱フォントは SIL OFL 1.1）
- 技術構成：Kotlin + Jetpack Compose + Room + Preferences DataStore、`minSdk = 26`。`INTERNET` 権限は持たない

## 外部共有の仕組み
- Android の共有：`Intent.ACTION_SEND`、`text/plain`、`Intent.createChooser`（出典 https://developer.android.com/training/sharing/send ）
- ChatGPT・Claude・Gemini の Android アプリへの長文共有を確認済み。共有非対応環境向けに「コピー」も常に併設する

## データ設計（Room テーブル＋設定）

| テーブル / 保存先 | 単位 | 主なカラム |
|---|---|---|
| `sleep_records` | 1日1件（主キー: `date`） | `date`(YYYY-MM-DD), `sleepMin`, `wakeMin`, `napSleepMin`, `napWakeMin`, `updatedAt` |
| `condition_records` | 1日複数件 | `id`, `date`, `timeMin`, `mind`(1..5 nullable), `body`(1..5 nullable), `note`, `updatedAt` |
| `consult_memos` | 話すこと／話したこと | `id`, `text`, `kind`(`doc`/`coun`/null), `createdAt`, `talkedAt`(null=未相談) |
| `visits` | 診察・カウンセリング記録 | `id`, `date`, `kind`(`doc`/`coun`), `talkedSummary`, `feedback`, `createdAt` |
| `appointments` | 次の予定（相手ごと最大1件） | `kind`(主キー), `date`, `timeMin`(nullable) |
| `ai_summaries` | AIの整理（相手ごと0〜1件） | `kind`(主キー), `text`, `savedAt` |
| `settings` (DataStore) | アプリ設定 | `useDoc`(Boolean), `useCoun`(Boolean), `onboardingDone`(Boolean) |

### 整合性のルール
- 過去の記録を修正・削除すると、「これまで」「見せる」のグラフと平均は即座に再計算される。貼ってある `ai_summaries` は自動書き換えしない。
- `useDoc` / `useCoun` をオフにしても DB のレコードは削除せず、UI 表示と AI プロンプト生成対象から外すだけにする。
- 読み込み（リストア）を複数回行っても重複増殖しないよう、`sleep_records`・`appointments`・`ai_summaries` はキー単位で上書き、`condition_records`・`consult_memos`・`visits` は日時＋内容の一致で重複をスキップする。
- アプリを削除すると端末内のデータはすべて消える。書き出した JSON ファイルからのみ復元できる。
